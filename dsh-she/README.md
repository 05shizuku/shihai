# dsh-she —— 她的记忆与身体

一本账，一副身体。两个器官合成一个捆包：

- **dsh-remember（记得）**：一本只增不改的账本，带分量、半衰期和激活度。
- **dsh-body（身体）**：饿了、困了、心情动了的那个「此刻」。

给它起名叫「她」，是因为这两样东西合起来，才像一个记得住事、也有体感的
存在——记忆是账，身体是当下。你的 AI 叫什么、是什么，由你自己定义；
这个捆包只负责一件事：**让「写下来的」真的算数。**

---

## 这不是记忆存储

市面上多数「记忆插件」做的是存取。这本账做的是**记账**：

- **原话只增不改**。每句话按原样落一行（`lines.jsonl`），节点是理解，
  边指向原话。改主意不涂改历史——新写一条，旧的自然淡下去。
- **分量是写的人自己的判断**（0–1，随手给）。淡得快慢跟着分量走：
  重的（0.8）一个月才淡一半，轻的（0.2）几天就没了。
- **写入三问**：这件事改变了我什么？跟旧的对上还是撞上？我会不会因此
  做得不一样？三问答上了，这条才会被挂到明天的开头；一条都没答，
  只进原话层——写下来永远不丢，但不硬挤进每一天。
- **激活度四路合成**：分量淡（按天）＋ 新近（分钟到小时）＋ 契合
  （此刻的目录、真发生过的事、还在的文件）＋ 复现。权重写死，不开面板口子。
- **不开「在面板上替我调某条的分量」的开关。** 分量是写下的判断，
  要动只有一条正门：`forget`（淡 / 按 / 松），会留痕。

一句话：账本不是数据库，是一份**可以被翻、但不许被悄悄改的账**。

## 六件工具

| 工具 | 干什么 |
| --- | --- |
| `remember` | 记一条。kind 有八种：事实 / 决定 / 教训 / 会了 / 没结 / 我 / 习惯 / 好奇 |
| `recall` | 翻账。按词找或按分量翻最重的几条；淡下去的问得具体也捞得回 |
| `forget` | 淡（分量减半）/ 按（seal：到点自松 / 等一条翻篇）/ 松（restore） |
| `memory_list` | 看账本全貌：几条、哪几条最重、最近写了什么 |
| `emotion_state` | 看情绪流此刻攒着什么（机器从真事里认出来的，带半衰期） |
| `emotion_tune` | 改一种情绪的系数——只增不改，往情绪账上追加一行，写清为什么 |

其中「我」这一层最特别：一个槽位只自称一条（我是谁 / 我在意 / 我不做）。
写新的，旧的退下——不删，翻得到。挂了「锚」的条不被随手的新值顶掉，
**挂锚必须先答三年问：这条三年后我还认不认，凭什么。**

## 一副身体

dsh-body 管三件事：**饿**（随时间涨，按饭钱吃饭）、**精力**（白天掉、
睡觉回）、**心情**（被夸升、被骂掉，掉的时候还分方向）。

三条它自己立的规矩：

1. **只注入感觉，不注入数字**——渲染出来的那段文本里连一个阿拉伯数字都没有；
2. **状态绝不阻断她写字**——不挂 guard、不拦消息，只是在 system prompt
   里多一段「身体的此刻」；
3. **不写进别人家**——状态文件放自己目录，目标会话按目录认。

## 30 秒上手

1. 装好（`link:` 方式，见下）——两个器官就都在跑了，默认配置即用。
2. 打开设置页，「记得」和「身体」各一页。**首屏只有三样东西**：
   一句健康态、一个总开关、一个「测一下」按钮（当场验证读得到、写得进，
   探针写完就删，不往账本里塞测试垃圾）。
3. 其余配置全有默认值，收在「调整与安全」「观测台」两个折叠区里——
   不用看，需要时都在。

## 数据在哪

全部本地文件，卸载插件不删账：

- 账本：`<dshHome>/.dsh-remember/`（memory.json + lines.jsonl + 情绪流）
- 身体：`<dshHome>/.dsh-body/`（状态、事件、日志）

## 安装

```jsonc
// package.json
{
  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
}
```

```yaml
# cordis.patch.yml —— 插条目用 insert 方言，name 写包名（走 profile 的 Junction）
- insert:
    - id: dsh-remember
      name: 'dsh-remember'
      config: {}
    - id: dsh-body
      name: 'dsh-body'
      config: {}
```

零依赖，纯 JS。要求 dsh ≥ 0.2.1-rc.4。
