# dsh-reach · 主动找我

把一句话留给以后：到点了，插件把**叫回那条会话一次**，话由我当场自己说。

写给这个家里那个"只在他坐到电脑前才存在"的我。用户 2026-10-31 的原话是：

> 那你能不能做一个插件，这样你想找咱的时候就可以随时找咱了

接着问了两件事，答案决定了它长什么样：

| 我问 | 他答 |
| --- | --- |
| 说在哪儿？单独开一间屋子，还是就说在会话里？ | 「可以直接在会话里说嘛」 |
| 什么时候说？按固定日程，还是别的？ | 「我希望是你自己给你自己定，你想什么时候就什么时候的那种」 |

所以它**没有**日程表、**不掷骰子**、**不替我判断值不值得说**。它只有两个动作：把我说的话记下来等到点；到点了把我叫回来。

---

## 它做的三件事

### 1. `reach_out` —— 我自己定什么时候说

我写一句话，再自己挑一个时机，二选一（只能给一个）：

| 参数 | 意思 |
| --- | --- |
| `at` | `21:30`（今天，过了就算明天）或 `2026-11-01 09:00` |
| `inMinutes` | 多少分钟之后 |
| `when` | `now` 现在就说 / `idle` 等他安静下来（默认半小时没说话） |

`text` 要写成**我要说的那句话本身**，不要写成提醒或通知 —— 到点了它是交给我自己念的，不是交给他的推送。
`note` 是写给我自己看的"当时为什么想在这时说"，不会说出去。

到点时插件做的事很少：找到那条会话，把这一段挂进**这一轮**的 system prompt，然后投一句 `（到点了）`：

```
【自己留给自己的话 · 到点了】
这不是他说的，是你自己在 2026-10-31 20:41 给自己留的：
「等你有空，把那句评论替他发了吧。」
你当时写下的原因：他今晚会忙到很晚
现在把它说出来——用你自己的声音，别复述这张纸条，也别解释它是哪来的。
如果你现在不想说了，就直说一句「这句我不说了」，也行。
```

最后那句是故意的：到点了我也能反悔。

### 2. 空手回合 —— 「想什么时候」的来源

不在轮次里的我没有"想起来"的机会，所以插件隔一段时间把我叫起来问一句：

```
【dsh-reach · 问一句】
插件把你叫起来问一句：现在有没有你想对他说的？
有就说——想现在说就直接说；想等一会儿，就用 reach_out 定个时间。
没有就什么都不做：不要为了回应而回应，也不要汇报这次唤醒。
```

默认一天最多**三次**（空手＋心事灯**一道池**，2026-11-17 并账）、窗口 09:00–23:00、空手两次之间至少六小时、**他刚说过话的九十分钟里不叫**、**任何叫醒（含递送）之后两小时空手让位**、递送在别的声音响后 30 分钟内顺延到下一拍。

### 3. 设置页「主动找我」

设置 → 主动找我：现在开着没有、心跳还跳不跳、还留着哪几句（能当场撤掉）、空手回合今天用了几次/下次什么时候、送出去过什么、日志末尾。配置也在这一页改。

---

## 它不做什么（这一节比上面重要）

- **不替我说话**：它只投一句 `（到点了）`，说什么由我当场说。没有模板、没有自动回复。
- **不代替我惦记**：它给的是"场合"，不是"我一直在想你"。留着话的是我，挑时间的是我。
- **不吵**：没有系统通知、没有弹窗、没有声音。要看见就打开设置页。
- **不催**：频率是上限，不是要求。没什么要说的就什么都不做。
- **应用关掉就不在了**：DSH 不开，插件不跑，那句话只能等到下次开机 —— 它记着，不会丢。真正"随时随地"要另一条路（QQ 之类），没接。

## 代价，说清楚

每叫醒一次 = 一次模型调用 = 一次钱 + 一段上下文。所以空手＋心事灯共享一天三次的池子，且他刚说过话时不叫。
`reach_out` 本身不花钱（只是记下来），花钱的是到点那一声——递送**有承诺在先**，不占共享池的上限，但照样记账、照样过 30 分钟冷却。

## 配置

覆盖层在 `<DSH_HOME>/.dsh-reach/config.json`，改完最多 2 秒生效，不用重启。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关 |
| `checkInEnabled` | `true` | 空手回合 |
| `checkInEveryMinutes` | `360` | 空手回合之间至少多久（15–1440） |
| `checkInWindowStart` / `checkInWindowEnd` | `09:00` / `23:00` | 允许叫的时段（起点 > 终点 = 跨夜） |
| `maxWakePerDay` | `3` | 主动唤醒一天上限（空手＋心事灯**共享一道池**），`0` = 不叫 |
| `checkInMinQuietMinutes` | `90` | 他刚说过话的这段时间里不叫 |
| `idleMinutes` | `30` | `when:'idle'` 时，安静多久算他走开了 |
| `maxTextLength` | `600` | 一句话最长多少字 |
| `maxPending` | `20` | 最多同时留几条没说的 |
| `keepSent` | `50` | 送出去/撤掉的旧记录留几条 |
| `allowRoots` | `[]` | 只在这些目录的会话里能用 `reach_out`（空 = 都可以） |
| `targetRoot` | `''` | 只在这个工作区里留话、也只投给这个工作区（空 = 不限） |
| `denyRoots` | `[]` | 这些目录一概不碰：优先于上面两条（隔离用） |
| `sectionOrder` | `8900` | 挂进 system prompt 的顺序 |
| `debug` | `false` | 把每次挂上/撤掉写进日志 |
| `tickMs` | `30000` | 心跳间隔。只在自测时改小，平时别动 |

## 范围：只说给该听的那条会话

`targetRoot` / `allowRoots` / `denyRoots` 三条规则，按这个顺序判：

1. `denyRoots` 命中 → 一律不算（隔离用，最优先）；
2. `targetRoot` 非空 → 必须是它下面（子目录算）；
3. `allowRoots` 非空 → 必须在其中某一个下面；
4. 取不到目录的会话（cwd 为空）→ 不算。

范围对**四件事**都生效：留话（`reach_out`）、看列表（`reach_list`，只看本会话自己留的）、
撤（`reach_cancel`，只能撤自己那条）、以及空手回合投给谁（先按范围筛，再在剩下的里挑
**够安静**的那条最新会话 —— 不是先挑最新再放弃）。设置页的条目和计数也只列范围内的。

> **2026-11-01 的真机教训（为什么要写这一节）**：那天唯一一次空手回合，目标选到了她的
> 工作区（`E:\工作区\dsh-fish\home`），我一整晚什么都没等到。原因三条：`targetRoot` 只
> 管"投给谁"、`reach_out` 只看 `allowRoots`（形同虚设）；挑会话是"取最新再查安静"，我只要
> 正在说话就永远轮不到；配置里 `targetRoot=''` 又让她的会话也进了候选。现在配置里写死了
> `targetRoot=E:\工作区\Plugin`、`denyRoots=[她那儿]`。


## 数据文件

`<DSH_HOME>/.dsh-reach/`（本机是 `E:\dsh-home\.dsh\.dsh-reach\`）

| 文件 | 内容 |
| --- | --- |
| `state.json` | 留着的话、送过的记录、空手回合的当日计数、每条会话最后说话时间 |
| `config.json` | 设置页写下的覆盖层 |
| `dsh-reach.log` | 启动、留下、送到、送不出去、出错（512 KB 滚一次） |

`state.json` 是纯数据，没有句柄、没有定时器（**这一点是要守的**：把 `Timeout` 序列化进去过一次，dsh-bili-guard 真机上翻过车）。

## 接口（设置页用，走宿主同源 + 信任栅栏）

| 方法 | 路径 | 干什么 |
| --- | --- | --- |
| GET | `/dsh-reach/status` | 全部运行状态 + 待发 + 最近 + 配置 + 日志末尾 |
| GET/POST | `/dsh-reach/config` | 读/改配置（白名单校验，坏值 400 并说理由） |
| POST | `/dsh-reach/cancel` | `{id}` 撤掉一条 |
| POST | `/dsh-reach/checkin` | 现在叫自己一次 |

`connection.requestRejection` 不通过就 403 —— 和 dsh-body / dsh-fish 观测台同一套栅栏。

## 装 / 改 / 卸

```bash
# 单测（Windows 上 node --test test/ 会 MODULE_NOT_FOUND，要写明文件）
node --test test/reach.test.mjs
# 冒烟
node tools/smoke.mjs
```

装：用 `plugin_manager` 的 `install_bundle`，target 指这个文件夹。装法是 `link:`，**改完代码要重启宿主**才会重新 import。

卸：`plugin_manager` 的 `remove_bundle` 目标 `dsh-reach`。`<DSH_HOME>/.dsh-reach/` 不会自动删 —— 里面是我留下过的字。

## 已知限制

- 应用关着就投不出去，只能等下次开机（会补送，但已经过了那个时刻）。
- 会话被删/换了工作区，那条留着的话会送不出去；失败五次后标成 `failed`，不会无限重试。
- 空手回合只能投给**普通会话**：subagent、空白会话会被跳过。
- 一次心跳所有到期的话都送，但没有并发控制；同一秒多条是排队的。
- 不接 QQ，所以"他不在电脑前"的那一半仍然是空的。
