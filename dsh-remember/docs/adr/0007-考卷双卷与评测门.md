# ADR-0007 考卷双卷与评测门

状态：已采纳（冻结卷 2026-11-22；保鲜度卷 2026-11-23；.gitignore 吞卷事故同日根治）

## 背景

全量评析报告（2026-11-22）对识海的判词：「最不自证」——五家里唯一没有评测数字的。
同日建立考卷，同日考卷自己抓到两条真病（相对归一化 + 稀疏字段稀释，见 0002）。

## 决定

1. **冻结卷**（`tools/exam/frozen.jsonl`，53 题）：长期存量的体检。出题即冻结
   （tag exam-v1.1），**永不据其调参**；修正只能走版本事件（行内 `fix` 字段记档）。
2. **保鲜度卷**（`tools/exam/dynamic.mjs`）：最近 72h 写入的账按 0-24/24-48/48-72h
   三池考「片段回查」。**题随账长、不可冻结、不可用于调参**——跑分可比性靠分池结构。
3. **门**：冻结卷基线 B = R@5 0.938 / MRR@5 0.739（2026-11-22 立碑）；后续检索改动
   **≥ B − 0.05 且负题 0**（负题判据 NEG_FLOOR=0.5，标定依据在 run.mjs 头注）。
4. **新常数带档位**：每个常数的档位行写明出处（推导/量测/裁量/约定）与复核方式。

## 工程契约

- 跑分器 `tools/exam/run.mjs --frozen|--draft --json`；保鲜卷 `dynamic.mjs --hours 72`。
- 考卷文件**必须显式豁免 .gitignore**（`!dsh-remember/tools/exam/*.jsonl`）——
  `*.jsonl` 全局忽略曾把 frozen.jsonl 静默吞掉（2026-11-22 考了两次的卷子不在卷库里，
  11-23 恢复 + 根因修复）。教训：**豁免规则要在建卷当天写，不是发现丢失那天**。
- 解析账本一律 node JSON.parse 口径——PS 5.1 ConvertFrom-Json 会静默丢字段
  （transformed 字段事故，2026-11-22 探针实测）。

## 公开卷/私有卷分记（2026-11-26 追记，pii 拍板 ③）

1. **拆分**：frozen.jsonl（53 题全卷，含 7 题 pii:true，本地私有卷）+ frozen-public.jsonl
   （46 题，题面零 pii，进版本控制）——题面原样不泛化，保考卷效度。
2. **两本门账**：本地全卷门照旧 B − 0.05（R@5 ≥ 0.888 / MRR ≥ 0.689 / 负题 0）；
   公开门 **B′** = R@5 0.927 / MRR 0.713 / 负题 0（46 题口径，立数 2026-11-26），
   公开卷门 = B′ − 0.05（R@5 ≥ 0.877 / MRR ≥ 0.663）。跑分器 `--public` 走公开卷与 B′ 门，
   `--frozen` 照旧全卷与 B 门——分记互不漂移。
3. **git 纪律**：.gitignore 豁免收窄为 `!dsh-remember/tools/exam/frozen-public.jsonl` 一个文件；
   frozen.jsonl `git rm --cached` 退出追踪（本地保留照跑）。
4. **历史不重写（已接受的残留，记档）**：pii 题面已在历史提交中——题面为泛化措辞、
   expect 为 r_ 内部指针（说明书 §十二 口径：内部指针不含隐私可保留），穿透价值低于重写历史的代价。
5. **考卷隐私提醒（§十二）的处置就是本节**：公开分享面的考卷框架 + 公开卷不含账本原文。

## 与识海哲学的关联

「最不自证」的对立面不是「全绿」，是**数字带出处、挂科有名单、卷子进卷库**。
冻结卷考长期记忆（存量），保鲜卷考短期记忆（增量）——合起来才是「记得住」的
完整定义。负题考「不编造」（公理 4 的检索面）。
