# ADR-0005 受众三档

状态：已采纳（2026-11-17 v1.1.4，借自晴猫）

## 背景

群聊引入后出现新风险：私聊里记的账、群轮里顺手记的账，在另一个场被翻出来
——串台不是 bug，是「这一刻谁在听」没被账记住。

## 决定

1. **写入打标**：每条记忆/思量/智落账时记下「谁在听」——
   `solo`（只有她）/`private`/`group:群号`；旧行无标 = `any`（两边都可见）。
2. **recall 三档**（`recallAudience`）：`off`（现状，全可见）/
   `soft`（别的场的条排到尾上，降存在感还还给）/`hard`（别的场不翻出来）。
   solo 轮全可见，与现状一个样。

## 工程契约

- `currentAudience(now)` 从意图层最近一条「引起这轮」的事件现算；
  `audienceVisible(tag, turn)` 一处判定；
  recall 的 hard 分支在染色/违熏/缘起链之前过滤（:2607 附近）。
- status.audience = {mode, stamped}（打过标的新条数，旧条 any 不计）。

## 与识海哲学的关联

识海对不同的缘起现不同的行——对机说法不是虚伪，是「这一念本来就有听众」；
不透明性（方向七）的社交面：有些账只在 certain 耳边现行。
