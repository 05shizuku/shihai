# ADR-0002 四路真实信号

状态：已采纳（2026-11-08 v0.8.0；2026-11-16 补「展示不喂」拍板）

## 背景

激活度从老 score 升级时，最大的风险是自指：拿系统自己的输出喂输入，
分数会自我强化直到石化。

## 决定

1. 四路**真实**信号凸组合，权重写死不开面板口子：
   分量淡 0.45 / 新近 0.15 / 契合 0.25 / 复现 0.15（和为 1）。
2. **现行喂熏习**：recall 写 echo 行（kind:'echo'），按 τ=14 天指数衰减计入
   复现轴（ECHO_WINDOW_MS = 3τ）；唤醒即复习。
3. **展示只观测**：currentSection 挂到开头的 pick 记 display 行，**不进** repeatAxis。
4. 「待众缘」的升级（非线性聚合、新缘）冻结在此 ADR 之上：动 activation.js
   前必须先在 philosophy.md 新立拍板。

## 工程契约

- `lib/activation.js`：ACTIVATION_AXES / ECHO_TAU_MS / ECHO_WINDOW_MS / REPEAT_FULL。
- echoAt（id → 时间戳数组，上限 200）+ latestEchoRow（id → {at,rowId,query,with}）
  两个内存索引，唯一写入点在 loadEchoIndex 与 recallEcho 两处。
- 测试钉：违熏不进复现轴（activation.test）；展示不喂（philosophy 三理由）。

## 与识海哲学的关联

四路是「缘」的 v1 线性代理：待众缘的和合非线性升维是方向五的地盘，
但无论怎么升，「缘必须是真实的」这条底线不动——系统的自恋不算缘。
