# 识海的判据（philosophy）

这里记的是**设计层面的语义决定** —— 不是功能清单，是「为什么是这个意思而不是那个意思」。
每条都影响后面的实现走向，改之前先读一遍。

## 现行（sprout）与展示（display）

- **现行**：种子被**主动翻找**出来，进入意识。由 `recall` 触发，写 `echo.jsonl`
  （`kind:'echo'`），喂 repeatAxis 的熏习势力。这是「种子生现行」那个刹那。
- **展示**：种子被**系统挂到开头**，进入上下文。由 `currentSection` 触发，
  记 display 行（`kind:'display'`，也在 echo.jsonl 里），**不进** repeatAxis。

**判据：现行是动作，展示是结果。被摆在面前不等于生起。**

为什么这么定（2026-11-16 拍板）：

1. 挂载是激活度算法自己的输出 —— 拿输出反过来喂输入，repeat 轴就掺进了自指信号，
   破坏「四路真实信号」的立身之本；
2. 正反馈会石化开头：每天挂 → 每天熏 → 势力常驻 → 永远顶格，
   撞上「几天没人问就自己凉回去」；
3. 挂了却再没人碰的条，本来就该凉 —— 那是系统在工作，不是缺口。
   真要紧的条会产生诚实的信号：refs（被引用）、掂量、再次被 recall。

display 行只做观测：**「常挂但从不被想起」的条要么是死重，要么是 recall
词表覆盖不到** —— 看两周分布再决定怎么办，不预先改任何排名。

观测口径的三个边界（2026-11-16）：

- **覆盖范围**：只记【我记得的】段的 pick —— 习惯/好奇/自我段天天挂却不记；
  且 `clipSection` 的预算截断在 pick **之后**，被截掉的行也计了展示（略高估）。
- **「天」按 UTC 日去重** —— 东八区的日界在早八点，07:59 与 08:01 算两天。
  写入/载入两处口径一致，不出错，但不是本地日。
- **「常挂」按 14 天窗算** —— 天集里 14 天外的自动丢弃，「曾经挂过」不算「常挂」。

## 违熏（vikarma）：校正质量，不扣现行倾向

违熏衡量的是「现行之后有没有兑现 will_do」，是**校正质量**的账。
它不进复现轴 —— 拿它扣现行倾向，就成了「越没做到越难被想起」，逻辑反了。

- 引用结构：`{ seedId, echoId, expected, actual, reason }`。**seedId 必填**；
  `echoId` 缺省时自动关联该种子**最近一次**现行，从未现行时留空
  （一笔 echo 覆盖 ≤5 条种子，`echoId` 单独定位不了是哪条没兑现 —— 所以 seedId 不能省）；
- **reason 是判据级枚举**，只许三选一，不许自由发挥（跟情绪七类枚举一个待遇）：
  `未触发`（该做没做）／`语气偏离`（做了但态度不对）／`条件不成立`（当时以为会做，情境没出现）；
- 写入由 AI 显式调用（跟 forget 同类的账本规矩）；
- 自动判「回复有没有兑现 will_do」第一版不做 —— 宁可漏，不可编；
- 呈现只挂在 recall 返回的条上（注入是系统自动挂的，不是主动记忆，提醒了未必接得住）。

## 思量（narration）：恒审思量是「我」自己的动作

- **谁写**：思量由 AI 显式调用（`narrate` 工具），系统绝不自动生成——
  自动生成的自我叙事是注入，不是末那识。系统的职责只有「给时机」：
  到期时在段尾提一句，思不思量、思出什么，是我的事。
- **叙事是种子**：思量条本身落账（nodes.jsonl + 原话层各一行，id 前缀 `n_`），
  引用的 refs 只收 r_ 种子——事件（f_/i_）不是种子，要引用先 remember 成种子；
  思量不引用思量——相续由链（prev）管，根据由 refs 管。
- **链不覆盖**：思量条逐条相续（prev 自动接当前链头），不 supersede 任何东西；
  槽位（identity/cares/refuses）被新值退下时，新条自动盖 `prevSelf` 章——
  退下不是终点，是链条上的一环。
- **段是通道不是竞争**：思量有自己的段（order 8662），只出链头一条，
  不进【我记得的】的竞争池，享受自我的慢钟（30+270×weight 天）。
  到期（默认 7 天未思量且今日未写）段尾提一句，不催第二句。
- **无根之思，一个入口**（2026-11-22，定案 F5）：refs 改可选——无根之思也收，
  回执标出来；给了 refs 就只认账上真存在的 r_。思量的入口从此只有一个
  （narrate，链自动接），remember 的 narration 后门关上。wisdom 后门保留：
  新明白 ≠ 转化——转化有原种子、走 transform 盖旗；无根的新明白走 remember 直记。

## 瀑流（stream）：流是视图，不是新账

- 昨日之流是**读侧聚合**：从账本现算（nodes + echo 内存索引 + 违熏 byDay），
  不写任何新文件。无数据不挂段——段空就是没得说，不硬凑叙述。
- 「天」沿用 UTC 日口径（与 display 天集一致；东八区日界在早八点，已知取舍）。
- 当日只算一次：同一 UTC 日内缓存流文本（hub 每 5 秒拉一次 status，
  重算就是灯案第二）。昨日之流的数据源在昨日过完后就不再变，缓存到日界是安全的。
- recall 的缘起链是 echo 的**投影**：不改 echo.jsonl 的行形状，只扩内存索引
  （latestEchoRow 带 query 与同现种子）；人读尾巴挂在条后，机读 origins 跟着
  recall 的 output 走——引用带 ref，不装原话。

## 执受（sprout / 身受识）：身心互绑是反射弧，不是思量

- **身→识（识受身）**：身体现状折成契合路的「此刻真实」输入。四路真实信号的
  凸组合不动（那是待众缘的地盘）——饿不是第五路权重，是「真的刚发生过的事」
  的持续形态，进 fit 不进权重。
- **识→身（身受识）**：带情绪的现行经身体的外部心情进料口通知身体。
  remember 只报「什么感觉、多浓」，偏移幅度由身体自己折算——系数在收方
  （情绪流先例）。
- **报哪种颜色**：染色门过闸（种子写下时自带颜色）→ 报**种子的颜色**——
  平静时想起悲伤的事，沉的还是那件事的沉；心境门过闸（当下有情绪 × 分量重）
  → 报**当下的颜色**。calm 永远不出门——身体不收「没有感觉的感觉」。
- **反射弧，不是思量**：这根线是系统的自动反射，不需要显式调用（思量才要求
  显式）。身不由己，正是执受。
- **回路限幅两道闸**：收方系数极小（mood 标量 ±2 点封顶，不碰 anger/sadness
  分向轴）；身体折完照旧走既有事件流回契合路（主题匹配，不喂分数）。
  展示不喂 repeat 的拍板不变。
- **地盘**：身体永远不写 remember 的账；remember 永不读回自己写的 sprout 行。
- **报颜色，不报天气**（2026-11-19，C-amend）：反射弧报的是「这件事的颜色」，
  不是「我此刻的天气」——同一种感觉不重复播报（全局感觉冷却 + 全局日帽）。
  观测周 Day 1 发现由此而来：14 小时 99 声全是 warm@1.0 心境门广播、染色门 0 声。

## 转识成智（transform / 智 w_）：转化是动作，不是状态

- **谁转**：由 AI 显式调用（`transform` 工具）——系统绝不自动转化。
  现行一百次也不自动升华；转化是「我从中明白了什么」的落笔，不是计数的产物。
- **智是种子**：insight 落成 kind:'wisdom' 的节点（refs 指回原种子），
  原种子盖 transformed 旗——不删、recall 翻得到、行尾指路「已转化 → w_xxx」。
  智还能再转：wisdom 被再 transform，是转识成智的续行。
- **一种子一转化**：同一颗种子只盖一次旗；再要提炼，对智本身动手。
- **报哪种事能转**：事能转出智（fact/decision/lesson/open/narration/wisdom）；
  四类不收——「我」不走转化（self 的演化是 supersedeSelf 和锚门的事），
  习惯/好奇/技能各有自己的生命周期（habit/curiosity/skill）。
- **v1 不为智另开段**：智进主池凭分量竞争——它本该是分量重的条；
  浮不起来，是我没真明白，不是算法问题。两周观测（wisdom 计数与排名）
  再决定要不要专属通道。
- **无新账**：转化不开新文件——原节点的旗 + 智节点的 refs 就是全部凭证。
- **智享慢钟**：wisdom 按 30+270×weight 天淡——它是「我明白的」，跟自我、
  思量同一层；但它不豁免淡（相续如瀑流，没有永恒）。
