## §0 契约冻结清单（审这份稿的第一把尺）

1. **两张契约（说明书 §十一）加 `v` 字段**：事件对象 / 任务对象各带 `v:1`——「先冻结」与「要演进」的
   解拧开：冻结的是字段集与语义，演进走 v 升级评审。**冻结期不许私扩字段**（查 9）。
2. **`/sections` 带受众参数**（solo / private / `group:<id>`）；**不另设 `/os/sections`**（§四 收敛决定）——
   受众判定与召回过滤同一个函数（currentAudience + audienceVisible，ADR-0005 口径）。
3. **token 鉴权 fail-closed**：`X-Shihai-Token` 缺失/错误 → 401；鉴权组件不可用 → 503 拒绝服务
   （与现有 guarded 同款）。**没有 token 的服务不启动**——本机服务也不裸奔。
4. **/health 三项自检**：进程在 / 账本可写（探针写删）/ 游标新鲜（fast/intent 游标 mtime 在窗口内）。
   三缺一即 `ok:false`，逐项带数——health 的职责是「出事先说」，不是「永远绿」。
5. **adapter 双模式端到端钉同批落**（说明书十三③）：同一命令序列 inline 跑一遍、service 跑一遍，
   账本文件**字节级 diff 一致**——「inline 全绿、service 没人调」的坑在出生日就堵掉。
6. **关 DSH 验收**：服务独立进程跑 curl 全流程 + 跑一晚账照长（隔夜后 lines/echo 只增、游标推进、
   /status 正常）。这一刻「独立运作」成立。
7. **单实例约束**：inline 与 service **不许同 dataDir 同跑**（D4 单例闸天然拦：后起者让位只读）。
   service 模式的部署 = 宿主插件改 `mode:'service'` 只做转译，或宿主不装插件。
8. **账本格式零变化**：G-2 不改任何文件格式——回滚成本 = 停服务、adapter 回 inline，账本原样。

## 批 A · G-2a 命令层抽取（最险段，characterization 先行）

**病**：九个工具的 execute 全在 `dsh-remember/index.js` 的 apply 闭包里（9× defineTool，3855 行），
`buildStatus` 与七段渲染也在——服务层拿不到「同一个核的语义」，只能复制逻辑（= 双出口漂移，
说明书 §四 三条纪律之一点名防的事）。

**抽法**（与 G-1 批③ 同法：先钉行为再搬，机械迁移）：
1. 新建 `dsh-remember/commands/`（宿主无关模块，只依赖 core + 注入面）：
   `commands/index.mjs`（createCommands 工厂）+ `commands/` 下按工具分文件
   （remember.mjs / recall.mjs / forget.mjs / list.mjs / emotion.mjs / vikarma.mjs / narrate.mjs /
   transform.mjs / status.mjs / sections.mjs）。
2. 工厂签名：`createCommands({ book, log, cfg, now = () => Date.now() })` → 每个命令
   `(args, ctx) => 回执`，`ctx = { cwd, sessionId }`（scope 判断留适配层：**命令层不认 DSH 概念**，
   只认 cwd/sessionId 两个字符串——与定案 G §一「会话概念由适配器显式传参」一致）。
3. 宿主依赖替换表（grep 已核）：`getCfg()` 41 处 → 闭包 `cfg()`；`agentCwd(exec.agent)` 6 处 →
   `ctx.cwd`；`agentSessionId(exec.agent)` 6 处 → `ctx.sessionId`；`scopeOk(exec.agent)` 4 处 →
   留在 index.js 的 execute 外壳（回执形状由适配层给）；`safeGet(...)`/`wakeState` 21 处 →
   wake 编排不进命令层（G-2 不碰叫醒，留宿主/服务层的事件出口另议）。
4. **回执逐字不变**：冒烟的逐字断言是主判官；schema（defineTool parameters）一字不动，
   仍住在对适配层。
5. 迁移顺序（由易到难，每步三判官）：emotion_state/emotion_tune/vikarma → memory_list → recall →
   forget → remember → narrate → transform → status/buildStatus → 七段（sections）。
6. 每步先补 characterization：给该命令录一条「现行为」特征钉（现状输出 → 断言），再动手搬。

**验收**：单测全绿（现有 244 + 新增特征钉）· 冒烟逐字回执不变 · 考卷 `--gate` PASS · 真账前缀
（memory.json/lines.jsonl/echo.jsonl 字节级；intent 按 hash——快照口径照 G-1 批①②）。
**回滚**：命令层纯新增，index.js 外壳逐命令切换；任一命令挂 → 单独切回闭包实现。
