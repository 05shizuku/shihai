## 批 B（v0.27.0 注意力批）

### B1 翻身位（自举悖论）

**纯函数** `core/search.js` 或 `core/memory.js` 新增 `pickResurrect(nodes, echoAt, now, opts)`：

- 池：`kind ∈ {fact, decision, lesson, open}` ∧ 未封存 ∧ 未 superseded ∧ 未 transformed
  ∧ **`!echoAt.has(id)`**（零现行）∧ **`at < now - 48h`**（新账不叫压在底下）
  ∧ 可传 audience 过滤（opts.audienceTurn + opts.audienceActive）
- 选：**weight 最高**（被埋是排程问题不是价值问题）；并列取 at 最早
- 返回该节点或 null

**recall 接线**（index.js :2181 items 组装后、:2226 recallEcho 之前）：

```js
// 翻身位（2026-11-25）：从没被现行过的老账，每次检索给一次被想起的机会
if (args?.query) {
  const pick = pickResurrect(nodes, echoAt, now, { audienceTurn, audienceActive })
  if (pick && !list.some((x) => x.id === pick.id)) {
    list.push(pick)   // 让下面的 recallEcho 把它记进熏习（第一次现行 = 翻身）
    items.push(`${pick.id} ${renderLine(pick, now, { byId: dir })}（翻身位：这条从来没被翻出来过）`)
  }
}
```

- echo 语义：翻身位被翻出 = **第一次现行**（11-16 拍板字面：现行 = 由 recall 触发）
  → 照写 echo → 进熏习循环 → 下次正常竞争。真相关会被再想起，不相关的 14 天 τ 内
  自然衰减回零——**自平衡，无需白名单**
- recall 的机读输出加 `resurrect: pick.id`（可选字段）
- 排除 transformed（智已代它上场）与 narration/curiosity/habit/skill（各有通道）
- **不写 echo 的反例钉**：翻身位出现在 items 但 recallEcho 的 ids 含它——单测钉这个
  含（这是「翻身」的机制含义）

### B2 执受阻尼双刀

**刀 a（连击强制静默）**——`core/protocol/book.js` sproutToBody + createBook：

- createBook 的 feelTracker 扩为 `{ dominant:'', at:0, streak:0, silentUntil:0 }`
- sproutToBody 循环内、双门通过后：
  ```js
  if (now < (book.feelTracker.silentUntil || 0)) continue   // 强制静默期
  ```
  写入前：
  ```js
  const withinStreak = now - (book.feelTracker.at || 0) < 60 * 60000
  const streak = withinStreak ? ((book.feelTracker.streak || 0) + 1) : 1
  if (streak >= 3) {
    book.feelTracker.silentUntil = now + 2 * 3600 * 1000
    book.feelTracker.streak = 0
    log('执受阻尼：60 分钟内第 3 次心头一动——强制静默 2 小时')
    continue
  }
  book.feelTracker.streak = streak
  book.feelTracker.at = now
  ```
  （原 `book.feelTracker.at = now` 行被这段吸收）

**刀 b（检索影响上限）**——recall 的 ctx.events 组装处（:1537 附近）：

情绪对「翻出什么」的影响封顶。超出的不进 ctx.events（不是删事件，是不喂检索）。
